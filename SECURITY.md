# Security Policy

## Supported versions

Boxology is currently an early-stage framework at version `0.0.0`. Security fixes are
made on the latest `main` branch; there are no supported release branches yet.

## Reporting a vulnerability

Do not disclose suspected vulnerabilities in a public issue, discussion, or pull request. Submit a
confidential report through [GitHub private vulnerability reporting](https://github.com/fontanierh/boxology/security/advisories/new).
This channel will be enabled before the repository becomes public. Include the affected revision,
impact, reproduction steps, and any suggested mitigation. Please avoid including real credentials
or private user data.

The maintainer will investigate, keep you updated when practical, and coordinate disclosure after a
fix or mitigation is available. If the report is not a vulnerability, it may be redirected to the
public issue tracker with your consent. The channel accepts Code of Conduct reports too.
